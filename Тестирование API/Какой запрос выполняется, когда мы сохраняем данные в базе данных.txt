В общем случае, когда мы сохраняем данные в базе данных, выполняется запрос на изменение данных (Data Modification Language, DML).
В зависимости от операции, это может быть один из следующих запросов:
INSERT — для добавления новых записей в таблицу.
UPDATE — для изменения существующих записей.
DELETE — для удаления записей.
UPSERT (или MERGE) — для комбинированной операции «вставить, если нет, иначе обновить».
